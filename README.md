## Building from Source

### Prerequisites

- Windows
- Visual Studio 2026 or later
- The .NET 10.0 SDK
- Visual Studio's **.NET desktop development** workload

### Getting the Source

Clone the repository:

```bash
git clone https://github.com/Maseya/UI.WinForms.git
```

Alternatively, download the repository source as a ZIP archive.

### Building

1. Open `Maseya.UI.WinForms.sln` in Visual Studio.
2. Allow Visual Studio to restore any required NuGet packages.
3. Build the solution using **Build → Build Solution** or `Ctrl+Shift+B`.

No additional setup or build scripts are currently required.

## Use of AI

AI tools are occasionally used as supplementary aids during development. Their
use is limited to specific tasks where they can improve efficiency or provide
useful assistance, including:

- **Testing:** Occasionally generating test cases or test code.
- **Debugging:** Assisting with bug investigation and suggesting potential
  fixes.
- **Design:** Providing input when exploring implementation or design
  alternatives.
- **Boilerplate:** Generating repetitive or routine code.
- **Graphics:** Assisting with drawing commands for particularly complex shapes.
- **Documentation:** Helping draft and organize repetitive or structured
  documentation. All AI-generated documentation is reviewed by the maintainer.

AI-generated output is never accepted blindly. Suggestions and generated content
are evaluated, reviewed, and adapted as appropriate before being incorporated
into the project.

The project is independently developed and maintained by its human maintainer.
Its direction, architecture, design, and implementation are driven by human
judgment, experience, and deliberate engineering. AI serves only as an
occasional productivity aid and does not independently direct or drive
development.

This project is built with an emphasis on thoughtful craftsmanship, code
quality, and a genuine passion for creating useful software.
