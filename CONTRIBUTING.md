# Contributing

Contributions such as bug reports, feature suggestions, documentation
improvements, and code changes are welcome.

## Before Contributing

Please review the following project documents:

- [Code of Conduct][code-of-conduct]
- [License][license]
- [README][readme]

By participating in this project, you agree to follow its Code of Conduct.

## Reporting Bugs

If you encounter a bug, please [submit a bug report][bug-report].

When reporting a bug, include as much relevant information as possible:

- A clear description of the problem.
- Steps to reproduce the issue.
- Expected and actual behavior.
- Relevant screenshots, error messages, or stack traces.
- Your operating system, .NET version, and Visual Studio version.

## Suggesting Features

Feature suggestions are welcome. Please [submit a feature request][feature-request]
describing:

- The problem or use case the feature addresses.
- The proposed behavior or functionality.
- Any relevant examples or alternatives you have considered.

Please note that not every suggestion will necessarily be accepted.

## Development Setup

See the [Building from Source][building] section for prerequisites and
instructions on building the project.

## Submitting Changes

For code contributions:

1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes and ensure the solution builds successfully.
4. Test your changes where applicable.
5. Commit your changes with a clear, descriptive commit message.
6. Open a pull request against the `main` branch.

## Pull Request Guidelines

Please keep pull requests focused and provide:

- A clear description of the changes.
- The motivation or issue addressed.
- Relevant screenshots or examples for UI changes.
- Tests or other verification performed.

Keep changes consistent with the existing coding style and project
conventions.

## Code and Documentation

- Prefer clear, maintainable, and readable code.
- Avoid introducing unnecessary dependencies.
- Update documentation when changing public APIs or behavior.
- Add or update tests when appropriate.
- Ensure that any third-party code or assets are appropriately licensed
  and attributed.

By submitting a contribution, you agree that your contributions will be
